# 海报现场问答

适合手机和电脑浏览的科研海报交流练习页，包含36组中英双语问答、16个红色重点问题和开场介绍。第31至36题为新增深入追问，可直接选择“深入追问 6”分类。

- 点击英文问题或英文回答播放预先生成的英文MP3，可暂停、停止和调整语速。
- 支持关键词搜索、分类筛选、重点练习、答案展开和单题链接分享。
- 英文音频及数字读法已预先生成，不依赖手机的系统语音引擎或英文语音包。上方“测试声音”可快速检查播放。
- 首次在线访问后可缓存问答页面；完整音频播放需要网络。
- 建议在 Safari 或 Chrome 中打开；微信内置浏览器可通过菜单选择外部浏览器。

内容用于海报交流练习。模型分解、器件工艺与初步血糖验证的证据边界在各题及资料说明中保留，不作为临床建议。

## 部署

这是静态网站，GitHub Pages 以 `main` 分支根目录发布。页面不依赖本地运行的服务，不需要第三方朗读API密钥。
